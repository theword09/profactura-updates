ProFactura 2.53.0

ProFactura updates itself: it offers each new version when you sign in. To install by hand:

Download ProSync-Setup-2.53.0.0.exe

What's new

  • The ProSync Agent starts: ProSync's setup carried two of its libraries in an older version - the console tool's, published into the same folder - and the agent stopped at once (Windows' error 1053). Installing 2.53 starts the agent already installed, by itself; the build now refuses a package whose libraries do not match, and should the agent ever stop on an error, it writes why in ProSync's log.
  • A pallet's sheet with accessory packages prints once: its preview no longer adds pages without end, and many packages go on over the next page. The packages' labels and the box sheets end too, however small the paper.
